# Chip's Challenge (Windows 3.1) for Android

An unofficial, from-scratch native port of the Windows 3.1 version of Chip's Challenge to Android (arm64), tuned for the Retroid Pocket Duo:
touch/gamepad/keyboard controls, FM (OPL3) or Android MIDI music, and a live level map on the second screen of dual-screen devices.
**No game data is included.** You need your own copy of the original game files (`CHIPS.EXE`, `CHIPS.DAT`, the `.WAV` and `.MID` files).
Chip's Challenge is a trademark/work of its owners; this project is not affiliated with or endorsed by them.

A small C engine on SDL2 that reads the user's OWN original files at runtime. Nothing from the original game is embedded in the APK,
the repo or any derived file: tiles, digits, panel and level data are decoded from CHIPS.EXE / CHIPS.DAT while the game runs.


## Layout
- `src/cc_data.c` CHIPS.DAT parser + CHIPS.EXE NE resource reader + DIB (RLE4) decoder
- `src/cc_engine.c` rules engine (follows `re/RULES.md`, see RULES_IMPL.md); `src/tile_tt.h` generated by `tools/gen_tt.py` from `re/tile_tables.txt`
- `src/cc_app.c` game flow, menu, save, software renderer into a 640x360 ARGB framebuffer, second-screen state packing
- `src/cc_audio.c` WAV effects + software MIDI synthesiser (CHIP01/02.MID rendered offline at start, looped)
- `src/cc_sdl_main.c` SDL2 front end (keyboard, gamepad, touch, JNI `nativeState`); `src/cc_headless.c` PNG/BMP frame dumper
- `apk/` Android project (package `com.chips.port`), `deploy/deploy-to-device.ps1`
- `tools/` `ne_res.py` (NE resource lister/extractor, uses Pillow to view), `dat_dump.py`, `ascii_map.py`, `mkfont.py`, `gen_tt.py`
- `test/test_rules.c` rule unit tests, `test/solve.c` BFS solver over the real CHIPS.DAT


## Build (Linux / WSL)
Needs the Android SDK (`ANDROID_HOME`, default `~/android-sdk`) with NDK 27.3.13750724, JDK 17, and SDL2 for arm64 (`apk/sdl/libSDL2.so`, not included; headers are in `apk/sdl/include`).

    bash build_desktop.sh          # desktop build of the engine, tests and the frame dumper (needs SDL2 headers/gcc)
    bash apk/build_all.sh          # native libs + apk/out/Chips-debug.apk

The repo contains a generic placeholder launcher icon. The debug build overlays `apk/android/app/src/debug/res` if you create it,
e.g. from the icon inside your own CHIPS.EXE (`tools/ne_res.py`); that folder is git-ignored.

## Install and data
Install the APK, then either use the folder picker in the setup screen or put your files in `/sdcard/Chips/data` (CHIPS.DAT, CHIPS.EXE, *.WAV, *.MID).
`deploy/deploy-to-device.ps1` automates install + data push over adb (use `-WhatIf` first).

## How it was made
The level format, rules and tile behaviour were reimplemented from analysis of the original binary (see `docs/FORMAT.md`, `docs/RULES_IMPL.md`,
`docs/MUSIC.md`) and validated with unit tests (`test/test_rules.c`) and a BFS solver over the real level set (`test/solve.c`).
The analysis material itself (`re/`, decompiler output) and any frame dumps are deliberately not part of this repository.
Developed with the help of Claude Code.
